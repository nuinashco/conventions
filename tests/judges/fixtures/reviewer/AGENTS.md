# AGENTS.md

demo. Architecture and extension recipes: [CONTRIBUTING.md](CONTRIBUTING.md). The general rules come from the
`conventions` and `nuikit` plugins of the nuinashco marketplace (enable once per machine:
`/plugin marketplace add nuinashco/conventions`).

## Commands

```bash
make setup        # uv sync + git hooks (pre-commit, commit-msg)
make check        # ruff, import contracts, pyright, pytest: must pass before every commit
make format       # ruff fixes + format
make configs      # regenerate configs/ after changing any config schema
demo-run          # one run; results in runs/<run_name>/
```

## Layout

- `src/demo/cli/`: one module per console script; the only place objects are wired together.
- `src/demo/config.py`: entry config schemas; `paths.py`: repository paths.
- `configs/`: Hydra YAML. Files starting with `# Generated by` mirror schemas: never edit them by hand.
  `configs/run.yaml` is the hand-written entry config: values for every run go there.
- `tests/` mirrors `src/`; `tests/test_invariants.py` holds the repo-wide checks.
- `scripts/`: exploratory or one-time runnables, never imported.
